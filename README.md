# Automated Waste Management System (Smart Trash Can)An IoT-enabled smart waste management system powered by Arduino.
The device measures the fill level of a trash can in real-time using an ultrasonic sensor, displays the capacity percentage on an I2C LCD, and automatically alerts municipal workers or management via GSM SMS when the bin reaches full capacity to prevent overflow.🚀 FeaturesReal-time Waste Level Monitoring: Calculates fill percentage ($0\% - 100\%$) based on calibrated bounds.Automated SMS Alerts: Sends location and fill status alerts via SIM800L GSM module when full threshold is breached.Guided Calibration Routine: Simple setup process on power-up to establish EMPTY and FULL distances dynamically for any container size.Anti-Flicker LCD Interface: Smooth visual updates showing live distance and fill status without screen tearing.Noise Reduction & Sensor Filtering: Multi-sample averaging logic filters out ultrasonic echo noise caused by uneven waste distribution.Spam Protection: Built-in cooldown timer prevents repeated SMS spamming while the bin remains full.🛠 Hardware RequirementsComponentSpecificationQuantityMicrocontrollerArduino Uno / Nano1Ultrasonic SensorHC-SR041GSM ModuleSIM800L1Display16x2 LCD with I2C Adapter (PCF8574)1Power SupplyStep-Down Buck Converter (e.g., LM2596) or 18650 Li-ion battery (3.7V - 4.2V for SIM800L)1Resistors1kΩ and 2kΩ (for SIM800L RX Voltage Divider)1 eachConnecting WiresJumper Wires (M-M, M-F)As needed🔌 Pin Mapping1. # 📜 Installation & Upload Steps
Connect your Arduino board to your computer via USB.Open the .ino sketch in the Arduino IDE.Go to Tools $\rightarrow$ Board $\rightarrow$ Select Arduino Uno (or Nano).Go to Tools $\rightarrow$ Port and select the active COM port.Click Upload.Open the Serial Monitor (set to 9600 baud) for debug output if required.
